# List of Sources
**All sources must be public domain or free to use.**
- Steamboat Willie (1928) - Simplest form of animation
- The Dover Boys at Pimento University (1942) - Common example of mid-budget animation
- Gulliver's Travels (1939) - Example of big budget film level of quality
- The Dover Boys ReAnimated Collab! (2019) - Different examples of digital animation in various styles

# List of Criteria
# 1. Silhouette Accuracy
1. Character outline shape
2. Limb thickness
3. Head-to-body proportions
4. Negative space inside the silhouette
5. Readability at a distance
# 2. Contour Line Quality
1. Line thickness variation
2. Line tapering
3. Smoothness vs wobble
4. Corner treatment
5. Broken vs continuous lines
# 3. Shape Language
1. Circular forms
2. Oval forms
3. Rubber-hose limbs
4. Facial construction
5. Simplification level
# 4. Internal Line Placement
1. Facial features
2. Clothing folds
3. Glove details
4. Ear construction
5. Mechanical object details
# 5. Value Structure
1. Percentage of black pixels
2. Percentage of white pixels
3. Mid-tone usage
4. Shadow placement
5. Contrast hierarchy
# 6. Shading Style
1. Correct colouring
2. Smoothness vs. coarseness
3. Shadows
4. Gradients
5. Shadow edges
# 7. Pose Fidelity
1. Head angle
2. Spine curve
3. Arm positions
4. Leg positions
5. Hand poses
# 8. Perspective and Staging
1. Camera angle
2. Character placement
3. Horizon line
4. Depth cues
5. Screen-space proportions
# 9. Animation-Era Imperfections
1. Line jitter
2. Registration drift
3. Hand-drawn asymmetry
4. Shape inconsistency
5. Stroke irregularity
# 10. Temporal Consistency (if comparing sequences)
1. Silhouette stability
2. Line popping
3. Stroke swimming
4. Texture crawling
5. Motion smoothness
